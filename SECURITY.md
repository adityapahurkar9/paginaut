# Security

## Reporting a problem

If you find a security problem in Paginaut (a document that can run code, read files it shouldn't, get past the
Android engine's sandbox, or get the updater to install something that isn't an official release), please report it
privately, not in a public issue:

**GitHub › Security › Report a vulnerability** on https://github.com/adityapahurkar9/paginaut/security

Say which version and platform (Windows, Linux or Android), and how to make it happen; a sample file helps if you can
share one. You'll get an answer, and the fix will be credited to you unless you'd rather not.

Everything else (crashes, wrong results, files that won't open) is welcome as a normal issue: in the app, Settings ›
About › Report a problem (desktop) or Settings › Report a problem (Android) fills one in for you.

## Supported versions

Only the newest release of each app gets fixes: the desktop app updates itself (Settings › About › Updates), and the
Android app updates through Google Play or the newest APK on the releases page.
